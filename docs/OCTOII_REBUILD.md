# Octoii 产品层重构

本计划从 `00c4ca1` 的产品能力和测试出发，重新实现 Octoii 的任务、扩展和客户端边界。切换使用新产品数据布局、初版协议和独立的 Node Home。当前实现提供能力清单与回归案例。

## 模块归属

| 位置 | 职责 |
| --- | --- |
| `core/`，Cargo 包 `octoii` | Thread、Turn、输入与附件、Agent 执行、工具准入、项目和权限，调用公开 Siphon SDK 和 `octoii-ai` |
| `extensions/` | 静态装配的 Base、Git、MCP、终端、浏览器、Claude Code 等产品能力 |
| `libs/` | 独立的 script、shell、text、image 处理库 |
| `apps/node/` | 装配、公开 HTTP 和 WebSocket、设备配对、鉴权、节点进程与磁盘目录 |
| `packages/client/` | 类型化协议、请求、订阅和重连 |
| `apps/web/` 与 `apps/desktop/` | 按任务功能组织的 Web 界面和 Electron 外壳 |
| `devxiyang/octoii-mobile`（私有） | iPhone 与后续 Android 的独立客户端、构建和发布，通过 Node 公开协议连接 |

Node 拥有执行和持久状态。项目是节点内可选的任务分组，Thread 绑定一个实际工作目录，Turn 执行该 Thread 的一轮工作。Octoii 的 Agent 负责上下文、工具和权限，Siphon 提供持久 Fiber、请求、快照和提交。Claude Code 通过模型 Provider 接入。

## 执行与一致性

- 一个 `threads.start` 接受普通目录或独立目录的意图。受理回执、Thread、首条输入和附件一次提交。相同调用者的请求键绑定内容与结果，取消或删除后重放原键不会新建任务。
- 普通任务使用选中的目录，无项目任务也保存已解析的实际目录。独立目录选择位于项目菜单，基准按需选择。Agent 可通过结构化的新 Thread 或子 Thread 操作执行用户明确要求的隔离工作。
- 独立目录默认位于执行节点的私有临时目录。Node 持久保存来源、固定基准提交、分支、绝对目标及尝试身份，使用 Siphon 请求调用 Git 能力。只有当前尝试可以绑定实际目录并放行。重启后按实际 Git 登记和归属核查上次尝试，无法确认时保留现场并报告。已运行的 Thread 遇到临时目录丢失时进入可见的待处理状态。
- Turn 的停止绑定确切执行身份，已提交结果继续可读。人工答复绑定精确请求身份，多个设备提交的第一个有效答复在同一个事务内消费。
- Node 通过 HTTP 接受命令、查询与文件，通过 WebSocket 推送视图和实时流。订阅从一致的提交点产生有界视图。重连以持久状态和历史游标校准，实时流可重置。设备会话撤销同时生效于现有订阅。
- 常规工具在对话显示摘要。终端、浏览器、文件、HTML、Diff 与审批在用户查看、接管或决策时呈现。普通 Git 交给 Agent，工作目录绑定归宿主。工具结果统一采用 `content / structuredContent / metadata`。

## 实施批次

| 批次 | 改造 | 验收 |
| --- | --- | --- |
| A0 | 确立计划，将现有 Node 新建 worktree 的默认根改为系统临时目录 | 真实 Git 仓库的 Node 规划返回私有临时目录内的绝对目标，计划阶段不产生 checkout |
| A1 | 将 `libs/octoii/` 迁到 `core/`，收紧 Cargo 层级检查 | `octoii` 是唯一直接依赖公开 Siphon SDK 的工作区包，工作区构建、分层检查及协议生成通过 |
| A2 | 重写 Thread 首次受理、实际目录绑定、精确停止和持久回执 | 带附件普通任务在已有目录执行，重复受理与重启不会重复输入，旧停止令无法停止后续 Turn |
| A3 | Git 作为节点持久请求，接入同一个 Thread 启动入口 | 真 Git 双目录隔离、Git 成功后回执丢失、迟到结果、准备取消，以及临时目录被清理的恢复均可辨认 |
| A4 | Node 公开协议与客户端整体切换 | HTTP 命令及查询、WebSocket 初始视图与更新、重连、双端答复、会话撤销与文件权限通过契约测试 |
| A5 | 简化 Web 新建页和 Thread 详情，接回工具及 Electron | 桌面真实任务和用户介入通过，常见路径只需选择项目和发送 |
| A6 | 私有移动端验证同一 Node 上的接续 | 桌面发起后退出，iPhone 蜂窝网络介入，再在桌面查看同一结果；Android 随实际产品周期推进 |

各批独立验收并提交。A1 为路径迁移，原包的 97 个跟踪文件迁至 `core/`，根 manifest、依赖层检查及现行架构文档同步。旧目录保护规则与这份方案的产品核心范围需要先对齐。A2 及以后通过公开 SDK 实现，涉及 Siphon 自身机制的发现单独列出。
