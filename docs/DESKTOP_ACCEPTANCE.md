## 发现与修复

原桌面壳重新打开窗口时总是加载根地址，虽然任务仍在运行、历史仍可访问，却不能直接回到刚才的会话。

现在由桌面主进程保存最后的应用路由：

- 复用 Web 的路由解析和序列化，不维护第二套会话路由格式。
- 按节点 Home 区分；显式指定连接地址时按 origin 区分，不将其他节点的会话直接恢复过来。
- 同一 Home 改变端口后仍可恢复会话；显式深链接和配对链接优先。
- 只保存根页面的规范化路由，不保存启动页面、外部地址或配对 URL。
- 用户明确切回新会话页时保存该选择。
- 小文件以原子替换写入，退出不依赖异步刷新；损坏或缺失的记录不阻止启动。

增加 4 项回归测试，覆盖重启与端口变化、节点隔离、新会话选择、凭证不落盘及损坏记录。桌面测试共 21 项通过，构建、全仓类型检查和 lint 通过。
